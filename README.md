# Question 1 Section B

## Emfuleni Municiplaity Console Application

### Technologies 
- C#

### Features 
This is a Console-based municipal service management application for Emfuleni Municipality. The purose of this system is to enable the municipality to capture resident information, record utility-related service requests, and manage the processing of these requests interactively according to their priority and urgency levels.
